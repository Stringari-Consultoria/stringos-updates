# StringOS — atualizações

Este repositório publica **somente os pacotes assinados** das versões do StringOS, como
repositório APT. O código-fonte não fica aqui.

Os computadores com StringOS buscam as atualizações sozinhos (menu S › Atualização de
Software). Não é preciso usar nada deste repositório manualmente.
